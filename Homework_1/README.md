# CS 6220: Homework 1 - Iris Flower Classification

This repository contains the setup and solution for Homework 1. It implements a machine learning pipeline using the Iris dataset with scikit-learn.

## Setup Instructions

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Jupyter Notebook**:
   ```bash
   jupyter notebook HW1_Data_Mining_Meghana.ipynb
   ```
   
## Project Files
- `HW1_Data_Mining_Meghana.ipynb`: The main notebook containing the data exploration and scikit-learn pipeline (Logistic Regression).
- `iris.data`: The Iris dataset.
- `requirements.txt`: Python package dependencies.
