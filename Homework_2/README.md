# CS 6220: Homework 2 - Linear Regression and Decision Trees from Scratch

This folder contains full Python implementations and an executed Jupyter Notebook. All models: Linear Regression via Normal Equations and Regression Decision Trees via recursive splits are implemented from scratch using NumPy, without relying on external machine learning frameworks like `scikit-learn`.

## Dependencies & Setup

All required packages are listed in `requirements.txt`:

```text
numpy 1.20.0
matplotlib 3.3.0
pandas 1.2.0
```

To install dependencies:

```bash
pip install -r requirements.txt
```

---

## Execution Instructions

Open and run all cells in `homework2.ipynb` interactively using Jupyter Notebook or JupyterLab:

```bash
jupyter notebook homework2.ipynb
```
